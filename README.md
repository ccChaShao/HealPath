# 愈之路

面向个人及家庭的健康资料记录工具。本目录包含可运行的本地 API、浏览器体验版和原生微信小程序源码。

当前为本地开发版本，尚未部署服务器，也尚未接入真实微信登录、OCR、微信订阅消息和跨账号家庭协作。

## 在这台电脑运行

已检测到 Node.js v24.15.0、npm 和 Git。当前服务使用 Node.js 内置 SQLite，无需安装数据库、Docker 或第三方 npm 依赖。

```powershell
cd 'D:\CharsiewLi\projects\健康之路'
npm.cmd start
```

在浏览器打开 <http://127.0.0.1:4317>。添加第一位家庭成员，即可开始使用。关闭终端会停止服务，数据不会随之消失。

如 4317 端口被占用，可为该终端设置 `$env:PORT = '4318'` 后启动；小程序使用的地址也需要在 `miniprogram/utils/api.ts` 中同步修改。

## 微信开发者工具

1. 安装微信开发者工具稳定版，官方入口：<https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html>。
2. 导入本项目目录。`project.config.json` 已设置 `miniprogramRoot` 和 TypeScript 编译插件，AppID 暂为游客标识 `touristappid`。
3. 工具若允许游客 / 测试项目，可用于本地页面开发；若当前版本要求 AppID，则按官方流程注册后填入 AppID。本地浏览器体验不受影响。
4. 保持本地服务运行；在开发者工具的本地设置中确认“不校验合法域名、web-view 域名、TLS 版本及 HTTPS 证书”。此设置仅用于本地开发。
5. 模拟器访问 `http://127.0.0.1:4317`。本地服务仅监听电脑的回环地址，手机中的 `127.0.0.1` 指向手机，不能用于真机访问本服务。真机联调需要后续受保护的 HTTPS 测试环境。

目前没有在这台电脑上检测到微信开发者工具安装记录；小程序已做 TypeScript 静态检查，仍需在官方工具中编译和真机验证。浏览器界面与小程序共用 API 和数据，页面呈现各自适配。

## 已实现的本地功能

- 家庭成员新增、编辑、切换和删除；记录合法管理授权确认。
- 就诊记录：医院、科室、日期、症状、诊断摘录与医生建议。
- 健康时间线：首页入口和档案页，支持手动补录任意日期的经历；按月份/日期分组，可搜索标签和内容、筛选事件类型、切换日期排序。只填日期和标题即可保存，医院、科室、健康标签及详细经过选填。已有就诊记录继续显示，关联报告保持不变。
- 报告：分类、关联就诊、JPG/PNG/PDF 原件上传、查看、重复文件检查。
- 手动录入 12 种常见检验指标；保留单位、参考范围和原报告异常标记；核对后参与趋势。
- 浏览器端选择 2～5 份报告并列查看，前两份可做原件对照；小程序支持选择两份报告逐项及原件对照。
- 指标历史：不同单位、标本、方法或有界/文字结果不计算变化；同日多次结果在未记录时刻前不推定先后顺序。浏览器对可比结果绘制折线，小程序当前显示历史列表及变化值。
- 日历：一次性、每日、每周计划；按次完成、跳过、撤销；浏览器提供周/月视图，小程序提供周视图和原生日期选择。
- SQLite 持久化、编辑版本冲突检测、报告修订留痕、按成员导出 ZIP（含原件与 JSON）和删除。小程序导出入口当前引导到浏览器执行。

## 本地数据与边界

时间线使用方法：在首页选择“添加时间线”，或进入“健康档案 → 健康时间线”。填写实际发生日期和标题（如“甲状腺复诊”），保存后自动回到时间线。提供今天、昨天、前天、三个月前的日期快捷键；三个月按自然月回溯，无对应日期时取目标月末，例如 5 月 31 日回溯三个月为 2 月末。历史补录按发生日期排序，不按录入时间排序。同一天可以有多条记录，每位成员的时间线独立保存。

小程序从首页时间线、档案时间线或底部加号进入；点击已有条目即可编辑。日期、分组和搜索规则与浏览器共用。

数据保存在 `.data/health.sqlite` 和 `.data/uploads/`，已加入 `.gitignore`。SQLite 使用 WAL 模式；手动备份整个 `.data` 目录前应先停止服务，避免单独复制数据库主文件时漏掉未合并的 WAL 内容。

本地会话只用于限制其他网站跨站调用本服务，**不等于生产账号体系**。能够使用这台电脑和本地服务的使用者可以管理所有本地成员。真实云端部署前必须替换为微信身份验证和按账号的逐成员授权，不能将此服务直接暴露到公网。

本地文件未做应用层加密、恶意文件扫描或自动异地备份。当前不要把它当作唯一的医疗资料备份。上传上限为每文件 15 MB、每报告 30 个文件；单次 ZIP 导出原件总量上限为 200 MB。

小程序临时预览文件由微信缓存机制管理，后续需补充敏感缓存的明确清理和真机验证。OCR 尚未接入，不会把资料发送给第三方识别服务。

删除会移除本地记录、相关修订、原件和日历执行记录；此前手动导出的 ZIP 和手动备份不会被自动删除。

## 项目结构与验证

```text
server/       本地 HTTP API、校验、对比逻辑、SQLite 与 ZIP 导出
web/          浏览器体验界面
miniprogram/  原生微信小程序 TypeScript / WXML / WXSS
tests/        关键规则及 API 集成验证
.data/        本地数据，运行后生成，不提交
```

```powershell
npm.cmd test
npm.cmd run check:mini
```

小程序类型检查使用本机已有的 `tsc`（TypeScript 5.4.5）。换机器后如没有该命令，可安装 TypeScript，或使用微信开发者工具的 TypeScript 编译能力。当前保留最小平台类型声明，正式开发阶段可引入官方 `miniprogram-api-typings` 加强平台 API 校验。

测试使用独立临时数据库，不读取或修改真实 `.data`。测试覆盖字段校验、不可比结果、报告修改冲突、成员归属、重复事项历史、上传格式与重复检查、原件下载、重启持久化、ZIP 导出及删除。
